# Лабораторна робота №2 — Music Collection CRUD

Розширення CRUD-застосунку на React.

## Реалізовано

- CRUD-операції з музичними композиціями
- Context API для глобальних налаштувань
- Збереження налаштувань у LocalStorage
- Світлу й темну теми
- Українську та англійську мови
- Пошук, фільтрацію та сортування
- Пагінацію
- Масове видалення з підтвердженням
- Попередження про незбережені зміни

## Запуск

Встановити залежності:

npm install

Запустити JSON Server:

npx json-server src/api-mock/db.json --port 5174

В іншому терміналі запустити React:

npm run dev

## Перевірка

npm run lint
npm run build
