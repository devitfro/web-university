# Лабораторна робота №5 — Варіант 12: Музична колекція

Адаптація наданого шаблону Angular. Збережено підхід standalone, ApiService, реактивну форму, CRUD через HttpClient, маршрутизацію, модальне підтвердження та пагінацію.

## Запуск

```bash
npm install
npm run server
```

У другому терміналі:

```bash
npm start
```

Вебзастосунок: http://localhost:4200/songs
API: http://localhost:5174/songs

Поля: назва пісні, виконавець, альбом, рік. Додаткова функція: фільтр за виконавцем.

## Перевірка
1. Додати пісню та перевірити появу в таблиці.
2. Відредагувати її через окремий маршрут `/songs/:id/edit`.
3. Обрати виконавця у фільтрі.
4. Видалити запис після підтвердження.
5. Перевірити сортування та пагінацію.

Для звіту зробити скріншоти списку, форми, редагування та фільтрації.
