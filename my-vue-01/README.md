# Лабораторна робота №3 — Музична колекція (варіант 12)

Vue 3 + Vite + Vue Router + Axios + JSON Server.

## Запуск

```bash
npm install
npm install -D json-server
npm run server
```

В іншому терміналі:

```bash
npm run dev
```

Інтерфейс: http://localhost:5173/songs
API: http://localhost:5174/songs

Реалізовано CRUD, пошук за назвою, фільтр за виконавцем, сортування, пагінацію, валідацію та модальне підтвердження видалення.
