# Лабораторна робота №4 — Варіант 12

Проєкт `my-vue-02` — музична колекція (Vue 3 + Pinia + vue-router + axios + json-server).

## Запуск

```bash
npm install
npm run server
```

В іншому терміналі:

```bash
npm run dev
```

Відкрийте адресу Vite (зазвичай http://localhost:5173).

Реалізовано CRUD композицій, пошук, фільтрацію за виконавцем, сортування, пагінацію, Pinia + LocalStorage, світлу/темну тему, вибір і масове видалення, захист від втрати незбережених змін через router guard та beforeunload.
